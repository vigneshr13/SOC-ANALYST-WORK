# SOAR Automation

Security Orchestration, Automation and Response workflows.

## Shuffle Playbooks (`shuffle-playbooks/`)
Exported Shuffle SOAR workflow definitions:
- Automated alert triage and enrichment
- IOC lookup and reputation checking
- Ticket creation in TheHive from SIEM alerts
- Automated email notifications for critical alerts

## Python Scripts (`python-scripts/`)
Custom automation scripts:
- MISP API integration for IOC ingestion
- TheHive API for automated case creation
- Log parsing and normalization utilities
- SHA-256 hashing scripts for PII masking
- Splunk REST API query automation
